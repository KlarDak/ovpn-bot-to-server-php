# Список допустимых ошибок

Ниже представлена таблица ошибок, допустимых в библиотеке.

|Ошибка|Описание|
|:--:|:--:|
|ApiException|Ошибка подключения к серверу через API|
|AppException|Ошибка получения доступа к переменной окружения|
|ConfigException|Ошибка доступа к записи о конфиг-файле|
|DatabaseException|Ошибка подключения или выполнения запроса к базе данных|
|InvalidArgumentException|Невалидный аргумент десериализации объекта класса|
|TokenException|Ошибка дешифрования токена|
|UnexpectedValueException|Ошибка десериализации объекта класса|
|UserException|Ошибка доступа к записи о пользователе|
|GuzzleException|Ошибка подключения к API сервера|
