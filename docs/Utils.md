# Утилиты

В библиотеке имеются также два утилитарных класса, существующих для помощи в работе с разными методами.

## Utils

Класс со **статическими** методами для работы некоторых методов, преимущественно при получении конфиг-файла пользователя.

Для использования, укажите ``use CNS\OvpnBotToServer\Utils\Utils``

Метод ``Utils::timeGenerator($time, $minutes)`` используется для форматирования UNIX-времени в DATETIME-тип. В качестве аргументов: 
1. ``$time`` - время в UNIX-time виде.
2. ``$minutes`` - добавочные минуты к этому времени (не обязательно).

Возвращает ``string``.

```php
<?php

use CNS\OvpnBotToServer\Utils\Utils;

Utils::timeGenerator(time(), 2);
```

Также, в ``Utils`` имеются методы для работы с OpenVPN-конфигурациями пользователей. Все они возвращают значение ``boolean``.

**Важно:** для методов ниже необходимо подключение ``Env``-класса в файле обработчике.

**Возможные агрументы функций:**

1. ``$uuid`` - UUID-идентификатор конфиг-файла пользователя.
2. ``$file`` - содержимое конфиг-файла пользователя.

|Метод|Описание|Аргументы|
|:--:|:--:|:--:|
|saveOvpnFile()|Сохраняет данные в ``.ovpn``-файл| ``$uuid``, ``$file``|
|removeOvpnFile()|Удаляет ``.ovpn``-файл|``$uuid``|
|getOvpnPath()|Получить путь к ``.ovpn``-файлу|``$uuid``|
|isOvpnFileExists()|Проверяет, существует ли ``.ovpn``-файл|``$uuid``|

## JwtGenerator

Класс со **статическими** методами для шифрования и дешифрования токенов JWT, предназначенных для общения между серверами через API.

Метод ``JwtGenerator::decodeToken($token, $server_id)`` используется для дешифрования полученного при запросе JWT-токена. 

Работает на базе библиотеки ``JWT``.

В качестве аргументом передаётся ``$token`` - сам токен, и ``$server_id`` - идентификатор сервера под связкой из файла ``.env``.

Возвращает **полезную нагрузку** декодированного токена.

```php
JwtGenerator::decodeToken($token, $server_id);
```

Метод ``createToken($server_id, $exp, $role)`` создаёт JWT-токен и полезную нагрузку для отправки запроса на сервер.

Возвращает ``string``.

|Аргумент|Описание|
|:--:|:--:|
|$server_id|Идентификатор сервера из связки в файле ``.env``|
|$exp|Срок действия токена (время истечения действия)|
|$role|Роль отправителя: ``admin``, ``bot``, ``site`` или ``user``|

```php
JwtGenerator::createToken($server_id, $exp, $role);
```

Метод ``encodeToken()`` тоже создаёт JWT-токен, однако ему изначально нужно передавать полезную нагрузку. Является более "ручным" вариантом создания токена. 

Аргументы: ``$secret_key`` - секретный ключ сервера-получателя, ``$payload`` - полезная нагрузка.

Возвращает ``string``.

```php
JwtGenerator::encodeToke($secret_key, $payload);
```

Метод ``payloadGenerator()`` является помощником в генерации полезной нагрузки.

Возврвщает **массив** полезной нагрузки.

|Аргумент|Описание|
|:--:|:--:|
|$aud_id|Идентификатор сервера-получателя|
|$exp|Срок действия токена|
|$role|Роль отправителя|

Поле ``type`` удалено из JWT начиная с API v2.1. Токены, создаваемые API-клиентами библиотеки, имеют срок жизни 12 секунд.
