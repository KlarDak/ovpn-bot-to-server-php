# Сервисы

В этом разделе перечислены доступные сервисы для работы с API как в режиме файла-обработчика, так и в режиме ``cron``-задач.

## Работа с API через файл-обработчик

Для работы с API используется метод ``apiClient($server_id)``, где ``$server_id`` - буквенный идентификатор сервера из связки, указанной в ``.env``-файле.

Возвращает объект класса ``ApiUserClient``.

```php
use CNS\OvpnBotToServer\Services\ApiUserClient;

$apiServer = $botToServer->apiClient("RU");
// или
$apiServer = new ApiUserClient("RU");

```

Для работы API, под указанный в аргументе идентификатор **обязательно** должна быть создана связка данных для сервера-получателя: (пример для идентификатора ``RU`` - он идёт в начале каждой константы)

1. ``RU_SERVER_ADDRESS`` - полный адрес сервера (с портом)
2. ``RU_SERVER_INDEX`` - рабочий индекс сервера.
3. ``RU_SECRET_KEY`` - секретный ключ сервера.

**Важно:** без указанной связки попытка вызова любого метода HTTP-запроса вернёт ошибку типа ``ConnectException``.

### Доступные методы

Доступны методы под работу со всеми HTTP-методами, реализованными на конечном сервере.

Каждый из этих методов может принять один или все из следующих параметров:

1. ``$uuid`` - UUID-идентификатор конфиг-файла.
2. ``$time`` - время работы конфиг-файла (в секундах).
3. ``$type`` - тип конфиг-файла (``user``/``admin``/``unlimit``/``trial``).
4. ``$short_link`` - только для метода ``downloadConfig()``. Короткий идентификатор конфиг-файла.

Полная таблица типичных методов:

|Метод|Описание|Обязательные параметры|
|:--:|:--:|:--:|
|getConfig()|Получить данные конфиг-файла|``$uuid``|
|postConfig()|Создать новый конфиг-файл|``$uuid``, ``$time``, ``$type``|
|putConfig()|Перевыпустить конфиг-файл + обновить мета-данные|``$uuid``, ``$time``, ``$type``|
|patchConfig()|Обновить мета-данные конфиг-файла|``$uuid``. ``$time`` и/или ``$type``|
|deleteConfig()|Удалить конфиг-файл + мета-данные|``$uuid``|
|downloadConfig()|Скачать конфиг-файл|``$uuid``, ``$short_link``|

Отдельно, метод ``queryConfig()`` позволяет выполнять прямые запросы к любым ``endpoint`` сервера с любым указанным методом и любыми параметрами.

```php
$apiServer->queryConfig($method, $endpoint, $type, $params, $role);
```

где:

1. ``$method`` - HTTP-метод запроса.
2. ``$endpoint`` - эндпоинт назначения.
3. ``$type`` - тип пользователя-отправителя.
4. ``$params`` - параметры запроса.
5. ``$role`` - роль пользователя отправителя.

> На момент версии ``dev-2.1`` не рекомендуется к использованию по причине нецелесообразности.

## Работа с API через cron

Для работы с через ``cron``, реализован отдельный метод ``apiCronClient($server_id)`` с аргументом ``$server_id`` - идентификатором связки констант сервера-получателя из файла ``.env``. Возвращает объект класса ``ApiCronClient``.

```php
use CNS\OvpnBotToServer\Services\ApiCronClient;

$apiCronClient = $botToServer->apiCronClient($server_id);
// или
$apiCronClient = new ApiCronClient($server_id);
```

Доступны два метода:

``banUser($uuid)`` - блокировка конфиг-файла пользователя с указанным ``$uuid`` - идентификатором конфиг-файла. Возвращает ``boolean``.

```php
$apiCronClient->banUser($uuid);
```

``pardonUser($uuid)`` - разблокировка конфиг-файла пользователя с указанным ``$uuid``. Возвращает ``boolean``.

```php
$apiCronClient->pardonUser($uuid);
```

> Актуально на версию **dev-2.1**. В будущих версиях класс будет сильно изменён и дополнен.
