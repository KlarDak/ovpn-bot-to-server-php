# Типы объектов

В этом разделе инструкций описаны типы доступных объектов, представленных в классе.

## User

Объект данных пользователя.

|Имя|Тип|Описание|
|:--:|:--:|:--:|
|id|int|ID записи|
|user_id|string|User ID пользователя в Telegram|
|username|string|username пользователя Telegram|
|language|string|Буквенное обозначение языка пользователя|
|configs_count|int|Количество конфиг-файлов|
|created_at|string|Дата создание аккаунта|
|expired_at|string|Дата истечения оплаты аккаунта|
|last_payment_at|string|Дата последней оплаты услуг|
|is_active|boolean|Активен ли аккаунт|
|disabled_at|string|Дата дезактивации аккаунта|
|is_dropped|bool|Удалён ли аккаунт?|

**Пример:**

```php
// Выведет ID зписи
print($user->id);
```

## Config

Объект данных конфиг-файла.

|Имя|Тип|Описание|
|:--:|:--:|:--:|
|ID|int|ID записи|
|uuid|string|UUID-идентификатор конфиг-файла|
|user_id|string|User ID аккаунта пользователя в Telegram|
|type|string|Тип конфиг-файла пользователя|
|location|string|Локация (сервер) конфиг-файла|
|created_at|string|Дата создания записи|
|status|boolean|Статус активности конфиг-файла|
|blocked_at|string|Дата блокировки конфиг-файла|
|is_dropped|bool|Удалён ли конфиг-файл?|

**Пример:**

```php
// Выведет ID зписи
print($config->id);
```

## Response

Объет данных ответа сервера через API.

|Имя|Тип|Описание|
|:--:|:--:|:--:|
|code|int|Числовой код ответа|
|message|string|Текстовое сообщение ответа|
|data|array / null|Данные ответа|

**Пример:**

```php
// Выведет числовой код ответа
print($response->code);
```

## Payload

Объект данных полезной нагрузки JWT-токена.

|Имя|Тип|Описание|
|:--:|:--:|:--:|
|sub|string|Сервер-отправитель|
|aud|string|Сервер-получатель|
|iat|int|Дата создания|
|exp|int|Срок истечения|
|role|string|Роль отправителя|
|type|string|Тип запроса|

**Пример:**

```php
// Выведет роль отправителя
print($payload->role);
```

## Env

Не является объектом. Представляет из себя класс ``Env`` со статическими методами для работы с данными ``.env``-файла.

**Важно:** для работы данного класса, необходимо подключение класса ``Dotenv/Dotenv`` в файле-обработчике.

```php
    Dotenv::createImmutable(__DIR__ . '/../')->load();
```

|Имя|Описание|Ответ|
|:--:|:--:|:--:|
|getToken()|Токен бота|string|
|getSecretToke()|Секретный ключ сервера|string|
|getConfigsDir()|Директория конфиг-файлов пользователей|string|
|getAddressByID($id_name)|Адрес выбранного сервера|string|
|getIndexByID($id_name)|Индекс выбранного сервера|string|
|getSecretKeyID($id_name)|Секретный ключ сервера|string|
|getSubIndex()|Индекс сервера|string|

Отдельно описаны **два метода:**

``Env::getDatabaseKeys()`` - возвращает объект данных для авторизации в базе данных.

**Ключи объекта:**
1. ``DB_HOSTNAME`` - хост базы данных.
2. ``DB_PORT`` - порт базы данных.
3. ``DB_USERNAME`` - имя пользователя база данных.
4. ``DB_PASSWORD`` - пароль пользователя базы данных.
5. ``DB_DATABASE`` - имя базы данных.

``Env::getRedisKeys()`` - возвращает объект данных для авторизации Redis.

**Ключи объекта:**

1. ``REDIS_HOSTNAME`` - хост Redis-сервера.
2. ``REDIS_PORT`` - порт Redis-сервера.
