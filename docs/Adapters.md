# Доступные адаптеры для работы с базой данных

В этом разделе документации перечислены доступные классы и методы для работы с таблицами пользователей и записей о конфиг-файлах.

## Работа с пользователем

Для работы с определённым пользователем используйте метод ``user()`` с аргументом ``user_id`` - ID пользователя в Telegram / ином мессенджере. Возвращает объект класса ``userAdapter``.

```php
use CNS\OvpnBotToServer\Adapters\userAdapter;

$user = $botToServer->user(1);
// или
$user = new userAdapter($db, 1);
```

Для получения объекта данных пользователя ``User``, используйте метод ``getUserByID()``.

```php
$user->getUserByID();
```

Метод ``updatePaymentInfo()`` используется для обновления данных об оплате услуг пользователем. В качестве аргументов передаются ``$expired_at`` - новое время истечения срока оплаты, и ``$last_payment_at`` - время последней оплаты. Оба значения передаются в **UNIX-значении**.

```php
/**
 * return bool
 */

$user->updatePaymentInfo($expired_at, $last_payment_info);
```

Метод ``updateActiveStatus()`` используется для обновления статуса блокировки/разблокировки пользователя. В качестве аргументов передаются **два значения:**
1. ``$is_acitve`` - boolean-значение, где ``true`` - пользователь активен, ``false`` - пользователь заблокирован.
2. ``$disabled_at`` - числовое значение в **UNIX-формате**, обозначающее дату блокировки, если аргументом выше указано ``false``.


**Список других доступных методов:** (все функции ниже возвращают значение ``boolean``)

|Метод|Описание|Аргументы|
|:--:|:--:|:--:|
|createUser(``$username``)|Создание пользователя|``$username`` - username пользователя|
|updateUsername(``$username``)|Обновить username пользователя|``$username`` - новый username пользователя|
|updateLanguage(``$language``)|Обновить язык аккаунта пользователя|``$language`` - буквенное обозначение языка|
|updateConfigsCount(``$configs_count``)|Добавляет или уменьшает количество конфиг-файлов пользователя|``$confings_count`` - положительное или отрицательное число (для сложения с уже имеющимся)|

## Работа с записью о конфиг-файле

Используется для работы с каждой записью о конфиг-файле по отдельности.

В качестве аргумента передаётся ``UUID`` - уникальное кодовое обозначение каждого конфиг-файла. Возвращает объект класса ``configAdapter``.

```php
use CNS\OvpnBotToServer\Adapters\configAdapter;

$config = $botToServer->config('uuid');
// или
$config = new configAdapter($db, 'uuid');
```

Для получения объекта данных записи конфиг-файла, используйте функцию ``getConfig()``

```php
$config->getConfig();
```

Для создание новой записи, используйте функцию ``createConfig()`` со следующими аргументами:

1. ``uuid`` - UUID-идентификатор конфиг-файла.
2. ``user_id`` - ID пользователя в Telegram.
3. ``config_name`` - имя конфиг-файла, придуманное пользователем.
4. ``type`` - тип пользователя (``user`` /  ``admin`` / ``unlimit`` / ``trial``).
5. ``location`` - буквенное обозначение локации сервера. 

**Важно:** буквенное обозначение должно быть одинаковым с тем значением, что указано для сервера в файле ``.env``.

```php
/**
 * @return bool
 */

$config->createConfig("uuid", 1, "config_name", "user", "LOC");
```

Для изменения полей записи о блокировке или разблокировке конфиг-файла, используйте функцию ``updateActiveStatus()``:

```php
/**
 * @return bool
 */


$config->updateActiveStatus($status, $blocked_at);
```

где: 
1. ``$status`` - числовое обозначение *активности* конфиг-файла: ``1`` - конфиг-файл активен, ``0`` - конфиг-файл отключён. 
2. ``$blocked_at`` - время блокировки (в UNIX-формате).

**Список других методов, доступных в классе:** (все функции ниже возвращают значение ``boolean``)

| Метод | Описание | Аргументы |
|:--:|:--:|:--:|
|updateConfigName($name)|Обновление имени конфиг-файла|``$name`` - имя конфиг-файла|
|updateLocation()|Обновление обозначения локации конфиг-файла|``$location`` - буквенное обозначение локации|
|updateType()|Обновление типа конфиг-файла|``$type`` - тип конфиг-файла|
|deactivateConfigFile()|Полностью блокирует запись о конфиг-файле, удаляя её из выборки|-|

## Работа со всеми пользователями

> Используется преимущественно для работы в ``cron``-задачах.

Для получения данных о всех пользователях в базе данных, создан отдельный метод ``users()``. При его вызове, возвращает объект класса ``usersAdapter``.

```php
use CNS\OvpnBotToServer\Adapters\usersAdapter;

$users = $botToServer->users();
// или
$users = new usersAdapter($db);
```

Доступны два метода:

``getAllUsers()`` - возвращает список всех **неудалённых** пользователей (с параметром ``is_dropped = 0``). Возвращает массив объектов класса ``User``.

```php
$users->getAllUsers();
```

``getExpiredUsers()`` - возвращает список всех пользователей с истечёнными сроками оплаты доступа. Возвращает массив объектов класса ``User``.

```php
$users->getExpiredUsers();
```

## Работа со всеми конфиг-файлами пользователей

> Используется преимущественно для работы в ``cron``-задачах.

Используется для получения данных о всех конфиг-файлах пользователя, а также работы работе с ними.

В качестве аргумента передаётся ``user_id`` - ID пользователя в Telegram / ином мессенджере. Возвращает объект класса ``configsAdapter``.

```php
use CNS\OvpnBotToServer\Adapters\ConfigsAdapter;

$configs = $botToServer->configs(1);
// или
$configs = new ConfigsAdapter($db, 1);
```

Методы, содержащиеся в объекте класса, используются для получения **списка всех конфиг-файлов пользователя**, а также для обновления записей о **блокировки** и **разблокировке** конфиг-файлов.

Для получения списка всех конфиг-файлов пользователя, как объектов класса ``Config`` для работы с каждой записью отдельно, используйте метод ``getConfigsByUserID()``.

```php
$userConfigs = $configs->getConfigsByUserID();
```

Для обновления записи о блокировке и разблокировке конфиг-файлов пользователей, используйте методы ``blockConfigsByUserID()`` и ``pardonConfigsByUserID()`` соответственно.

```php
// Блокировка конфиг-файлов
$configs->blockConfigsByUserID();

// Разблокировка конфиг-файлов
$configs->pardonConfigsByUserID();
```
