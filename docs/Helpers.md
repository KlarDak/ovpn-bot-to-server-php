# Скрипты-помощники в настройке баз данных и работе с cron

В данном разделе перечислены скрипты для настройки базы данных и скрипт работы через ``cron``.

## tablesInstaller

Используется единоразово, для стартовой настройки базы данных и таблиц.

> Для использования скрипта, необходим пользователей с привилегией **CREATE TABLE**.

Запуск скрипта

```bash
php tablesInstaller.php
```

## cronAnalyzer

Скрипт для автоматического обновления данных об оплате услуг пользователя. Для его работы, привяжите выполнение к ``cron``.

### Что внутри?

Внутри используются классы ``Env``, ``configsAdapter``, ``usersAdapter`` и другие, поэтому, для его работы, необходимо заблаговременно настроить файл ``.env`` полностью и правильно.

Скрипт получает список пользователей, у которых время действия услуг уже прошло, после чего блокирует его конфиг-файлы: обновляет данные и на сервере бота, и на сервере OpenVPN. 

В конце, отправляет уведомление пользователю через мессенджер Telegram.

### Настройка

Для настройки ``cron``, сделайте следующее:

Откройте панель ``cron``:
```bash
crontab -e
```

Добавьте следующее. Данная команда будет выполняться раз в минуту.

```bash
* * * * * php /путь/к/скрипту.php
```

Сохраните изменения.

Теперь скрипт будет автоматически проверять оплату услуг пользователем раз в минуту.

### Другие временные промежутки

Не рекомендуется, но допустимо установить другое время обновления пользовательских данных. Шаблон времени размещён в таблице ниже.

| Интервал | Cron |
|----------|------|
| Раз в минуту | `* * * * *` |
| Каждые 5 минут | `*/5 * * * *` |
| Каждые 10 минут | `*/10 * * * *` |
| Каждые 30 минут | `*/30 * * * *` |
| Каждый час | `0 * * * *` |
