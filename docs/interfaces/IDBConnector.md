# IDBConnector

Интерфейс реализации класса-адаптера работы с базой данных. Необходим для стандартизации возвращаемых результатов при запросах к любым типам реляционных баз данных (MySQL, SQLite, PostgreSQL, MSSQL и так далее).

## Важное уточнение

Интерфейс изначально предполагает, что в случае ошибок выполнения методов, связанных с транзакциями, класс реализации будет вызывать **исключение**, однако данное поведение не считается обязательным, если использована иная удобная реализация.

## Метод fetchOne()

Используется при запросе одной строки в качестве результата.

**Сигнатура**

```php
public function fetchAll(string $query, array $params = []) : ?array
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``query``|``string``|SQL-запрос|
|``params``|``array``|Параметры запроса|

**Возвращаемое значение**

``array`` при успешной выборке данных; ``null``, если выборка вернула 0 строк.

## Метод fetchAll()

Используется при запросе множества строк одновременно в качестве результата.

**Сигнатура**

```php
public function fetchAll(string $query, array $params = []) : array;
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``query``|``string``|SQL-запрос|
|``params``|``array``|Параметры запроса|

**Возвращаемое значение**

``Массив значений`` при успешной выборке данных; ``Пустой массив``, если выборка вернула 0 строк.

## Метод execute()

Используется для выполнения всех запросов, кроме предназначенных для получения строк (запросов ``SELECT``).

**Сигнатура**

```php
public function execute(string $query, array $params = []) : bool;
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``query``|``string``|SQL-запрос|
|``params``|``array``|Параметры запроса|

**Возвращаемое значение**

``true``, если запрос был выполнен успешно; ``false``, если запрос завершился неудачей.

## Метод insert()

Используется для SQL-запроса ``INSERT``. Возвращает значение ``ID`` новой записи.

**Сигнатура**

```php
public function insert(string $query, array $params = []) : int;
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``query``|``string``|SQL-запрос|
|``params``|``array``|Параметры запроса|

**Возвращаемое значение**

``int`` - числовое ненулевое значение.

## Метод beginTransaction()

Создаёт новую SQL-транзакцию.

**Сигнатура**

```php
public function beginTransaction() : bool;
```

**Параметры**

Нет.

**Возвращаемое значение**

``true``, если транзакция создана; ``false``, если транзакция не создана.

## Метод commit()

Фиксирует все изменения, выполненные в рамках транзакции.

``Сигнатура``

```php
public function commit() : bool;
```

**Параметры**

Нет.

**Возвращаемое значение**

``true``, если изменения зафиксированы; ``false``, если сохранение не удалось.

## Метод rollBack()

Отказывает изменения, выполненные в рамках транзакции.

**Сигнатура**

```php
public function rollBack() : bool;
```

**Параметры**

Нет.

**Возвращаемое значение**

``true``, если изменения успешно откатаны; ``false``, если при откате изменений произошла ошибка.
