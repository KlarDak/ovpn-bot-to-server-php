# HttpClientInterface

Интерфейс HTTP-клиента, используемого для взаимодействия с удалёнными VPN-нодами. Определяет методы отправки HTTP-запросов и получения ответов, включая потоковую передачу данных.

## Важное уточнение работы интерфейса

Интерфейс предполагает использование предварительно инициализированного HTTP-клиента. Настройка базового адреса, параметров подключения и авторизации осуществляется реализацией интерфейса.

## Метод request()

Используется для отправки запроса и получения ответа от сервера.

**Сигнатура**

```php
public function request(
    string $method,
    string $endpoint,
    array $options = [],
    array $headers = []
) : HttpResponse;
```

**Параметры**

|Параметр|Тип|Описание|По умолчанию|
|:--|:--|:--|:--|
|``method``|``string``|HTTP-метод запроса|-|
|``endpoint``|``string``|Эндпоинт запроса|-|
|``option``|``array``|Дополнительные параметры запроса|``[]``|
|``headers``|``array``|Дополнительные заголовки запроса|``[]``|

**Возвращаемое значение**

Объект ``HttpResponse``.

## Метод stream()

Используется для отправки запроса и получения ответа от сервера в виде потока.

**Сигнатура**

```php
public function stream(
    string $method,
    string $endpoint,
    array $options = [],
    array $headers = []
) : array;
```
