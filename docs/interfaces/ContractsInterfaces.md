# ContractInterfaces

В данном файле описаны необходимые методы, описанные в интерфейсах регистратора контрактов, кроме основного ``VPNNodeContractInterface``.

В ниже перечисленных интерфейсах поддерживается **один и тот же паттерн**:

1. В каждом интерфейсе - по одному методу.
2. Каждый метод возвращает значение ``mixed``, так как возвращаемые значения **могут меняться** от одного контракта к другому.
3. Возвращаемые значения стоит уточнять **в документации используемых контрактов**.

## AccessContractInterface

Описывает необходимый к реализации метод работы к доступами пользователей на VPN-нодах.

**Сигнатура метода**

```php
public function access() : mixed;
```

## ActiveContractInterface

Описывает необходимый к реализации метод получения информации об активных (``= подключённых к ноде``) пользователей в данный момент времени.

**Сигнатура метода**

```php
public function active() : mixed;
```

## MetricsContractInterface

Описывает необходимый к реализации метод получения данных метрики о выбранной VPN-ноде.

**Сигнатура метода**

```php
public function metrics() : mixed;
```

## SubsContractInterface

Описывает необходимый к реализации метод получения данных подписки пользователя на VPN-ноду.

**Сигнатура метода**

```php
public function subs() : mixed;
```

## SystemContractInterface

Описывает необходимый к реализации метод управления настройками VPN-ноды.

**Сигнатура метода**

```php
public function system() : mixed;
```

## TrafficContractInterface

Описывает необходимый к реализации метод получения информации о трафике, проходимом через VPN-ноду в данный момент.

```php
public function traffic() : mixed;
```
