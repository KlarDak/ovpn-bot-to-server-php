# Интерфейсы библиотеки BTS

В данном разделе описаны все доступные к реализации интерфейсы библиотеки BTS.

## Категория интерфейсов

- [ContractsInterfaces](ContractsInterfaces.md) - интерфейс, описывающий реализацию необходимых методов и их предназначения класса-фасада контрактов.
- [VPNNodeContractInterface](VPNNodeContractInterface.md) - интерфейс, необходимый для инициализации класса-фасада любой библиотеки. 
- [HttpClientInterface](HttpClientInterface.md) - интерфейс, описывающий реализацию фасадов HTTP-клиентов.
- [IDBConnector](IDBConnector.md) - интерфейс, описывающий методы класса-адаптера базы данных.
