# VPNNodeContractInterface

Данный интерфейс является главным для любого используемого в библиотеке контракта. Любой контракт, используемый в системе, обязан реализовывать как минимум данный интерфейс.

**Важно**

Если созданный вами контракт не реализует данный интерфейс, библиотека **не примет** его в работу, и вызовет к использованию заглушку ``NullContract``.


## Инициализация

Обознает, какие обязательные аргументы должен получать каждый контракт.

**Сигнатура**

```php
public function __construct(
    IDBConnector $dbConnector,
    HttpClientInterface $httpClient,
    BTSConfig $btsConfig,
    Server $server
)
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``dbConnector``|``IDBConnector``|Класс-адаптер для подключения к базе данных, реализующий интерфейс ``IDBConnector``|
|``httpClient``|``HttpClientInterface``|Класс-адаптер для работы с удалёнными VPN-нодами|
|``btsConfig``|``BTSConfig``|Класс-конфигуратор библиотеки, необходимый для работы системы|
|``server``|``Server``|Объект типа ``Server`` с информацией о выбранной VPN-ноде|

## Метод whichContract()

Метод, задача которого заключается в идентификации полного имени главного класса контракта.

Реализуется с помощью трейта ``CheckContractTrait`` или может быть реализован вручную.

**Сигнатура**

```php
public function whichContract() : string;
```

**Параметры**

Нет.

**Возвращаемое значение**

``string`` - строковое значение.
