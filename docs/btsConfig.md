# Класс-конфигуратор библиотеки BTSConfig

``BTSConfig`` - класс-конфигуратор библиотеки, предназначенный для установки необходимых констант при тестировании или в обход конфигурационного файла ``.env``.

Для его использования необходимо создать объект класса ``CNS\BotToServer\Config\BTSConfig`` и добавить его при создании основного объекта ``BotToServer``.

```php
require __DIR__ . "/vendor/autoload.php";

use CNS\BotToServer\Config\BTSConfig;
use CNS\BotToServer\BotToServer;

$btsConfig = new BTSConfig(
    encryptionKey: "TOKEN",
    role: "LIBRARY_ROLE",
    audCode: "YOUR_AUD_CODE",
    configsDir: "CONFIGS_DIR",
    logsDir: "LOGS_DIR",
    contracts: "CHOOSING_CONTRACTS"
);

$bts = new BotToServer(
    config: $btsConfig,
    ...
);
```

## Обязательные аргументы

Аргументы ``encryptionKey``, ``role``, ``audCode`` и ``configsDir`` являются **обязательными** при создании класса-конфигуратора. 

В случае, если аргументы не указаны, библиотека попытается получить их из файла ``.env``. Если файл недоступен, библиотека выбросит ошибку **о недоступности необходимых констант**.

## Описание аргументов

Ниже описаны аргументы, используемые при вызове класса:

|Имя аргумента|Описание|
|:--:|:--:|
|encryptionKey|Ключ шифрования токенов авторизации серверов|
|role|Имя роли-исполнителя запросов|
|audCode|Внутренний авторизационный код сервера-отправителя запросов|
|configsDir|Директория для временного хранения конфиг-файлов пользователей|
|logsDir|Директория хранения логов работы сервера|
|contracts|Массив контрактов, доступных для работы библиотеки|

## Подключение внешних контрактов

При необходимости использования контрактов, не находящихся в списке встроенных, **всегда** нужно использовать класс-конфигуратор ``BTSConfig``.

### Способ регистрации контракта

Регистрация контракта проходит через создание массива "**ключ -> значение**", где 
- **Ключ** - идентификатор типа VPN-ноды в базе данных.
- **Значение** - полное имя класса-фасада необходимого контракта.

**Пример использования**

```php
$btsConfig = new BTSConfig(
    contracts: [
        "openvpn" => CNS\BotToServer\Contracts\OpenVPN\OpenVPNContract
    ];
)
```

В случае необходимости, допустимо добавить и другие аргументы-переменные окружения.

### Использование ``BTSConfig`` при работе библиотеки

После создания класса-конфигуратора, используйте его при инициализации ``BotToServer``.

**Пример использования**

```php
$bts = new BotToServer(
    database: ...,
    http: ...,
    btsConfig: $btsConfig
);
```
