# AccessResource

Ресурс управления конкретной выбранной записью из базы данных о предоставлении доступа к VPN-ноде.

## Инициализация

**Через фасад**

```php
$bts = new BotToServer(...);
$access = $bts->access(uuid: $uuid); 
```

**Напрямую**

```php
$access = new AccessResource(
    dbConnector: $database,
    uuid: $uuid
);
```

**Параметры**

|Параметры|Тип|Описание|
|:--|:--|:--|
|``uuid``|``string``|Уникальный идентификатор записи доступа.|
|``database``|``IDBConnector``|Класс-адаптер, предназначенный для работы с базой данных. **Необходим при создании ресурса напрямую.**|

## Метод exists()

Проверяет, существует ли запись в базе данных.

**Пример использования**

```php
return $access->exists();
```

**Параметры**

Нет.

**Возвращаемый результат**

``true`` - если запись существует; ``false`` - если нет.

## Метод get()

Возвращает объект данных о записи, если она существует.

**Пример использования**

```php
return $access->get();
```

**Параметры**

Нет.

**Возвращаемый результат**

Объект класса ``Access``, если строка данных найдена.

**Исключения**

``AccessNotFoundException``, если запись не найдена.

> Актуально на ``3.0.0``. В последующих версиях поведение функции может измениться.

## Метод create()

Создаёт запись в базе данных о новом предоставленном доступе к VPN-ноде.

**Пример использования**

```php
return $access->create(
    userId: 12,
    AccessType: "openvpn",
    server_id: 1,
    name: "TEST"
);
```

**Параметры**

|Параметр|Тип|Описание|Обязателен?|
|:--|:--|:--|:--|
|``userId``|``int``|Уникальный числовой ``ID`` записи о пользователе|Да|
|``AccessType``|``string``|Тип конфигурационного доступа|Да|
|``server_id``|``int``|Уникальный числовой ``ID`` записи сервера|Да|
|``name``|``string``|Имя конфигурационного файла|**Нет**|

**Возвращаемый результат**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.

> Актуально на ``3.0.0``. В последующих версиях поведение функции может измениться.

## Метод update()

Обновляет имя конфигурационной записи.

**Пример использования**

```php
return $access->update(
    name: "NEW NAME"
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``name``|``string``|Новое имя конфигурационной записи|

**Возвращаемый результат**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.

## Метод block()

Обозначает запись о доступе пользователя к VPN-ноде/нодам, как заблокированную.

**Пример использования**

```php
return $access->block();
```

**Параметры**

Нет.

**Возвращаемый результат**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно. 

## Метод unblock()

Обозначает запись о доступе пользователя к VPN-ноде/нодам, как разблокированную.

**Пример использования**

```php
return $access->unblock();
```

**Параметры**

Нет.

**Возвращаемый результат**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.

## Метод drop()

Помечает запись о доступе к VPN-ноде/нодам, как удалённую. **Данное действие является необратимым.**

Несмотря на то, что внутренние методы библиотеки более не могут взаимодействовать с записью, **она остаётся в базе данных**.

**Пример использования**

```php
return $access->drop();
```

**Параметры**

Нет.

**Возвращаемый результат**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.
