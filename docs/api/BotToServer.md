# BotToServer

Главный фасад библиотеки. Используется для вызовов доступных в библиотеке классов-ресурсов.

## Создание

```php
$bts = new BotToServer(
    database: $database,
    http: $httpClient,
    ?btsConfig: $btsConfig,
);
```

**Параметры:**

|Параметр|Тип|Описание|Обязательный?|
|:--|:--|:--|:--|
|``database``|``IDBConnector``|Адаптер для подключения к базе данных, реализующий интерфейс ``IDBConnector``|Да|
|``http``|``HttpClientInterface`` \| ``string``|Адаптер (или класс адаптера) для работы с удалёнными подключениями, реализующий интерфейс ``HttpClientInterface``|Да|
|``btsConfig``|``BTSConfig``|Класс-конструктор конфигурационных констант и/или контрактов, доступных для работы в библиотеке|Нет|

## Метод user()

Предоставляет доступ к ресурсу управления конкретным пользователем по его Telegram ID или адресу электронной почты.

**Сигнатура**
```php
public function user(
    string|int $userIdentifier,
    UserType $userType
) : UserResource
```

**Параметры**
|Параметр|Тип|Описание|
|:--|:--|:--|
|``$userIdentifier``|``string``\|``int``|Telegram ID или email|
|``$userType``|``UserType``|Тип идентификатора: ``UserType::TELEGRAM`` или ``UserType::EMAIL``.|

**Возвращаемое значение**

``UserResource`` — объект для выполнения операций над выбранным пользователем.

**Примеры использования**

По Telegram ID:

```php
$user = $bts->user(123456789, UserType::TELEGRAM);
```

По электронной почте:

```php
$user = $bts->user('user@example.com', UserType::EMAIL);
```

Получение данных пользователя:

```php
$user = $bts
    ->user(123456789, UserType::TELEGRAM)
    ->get();
```
**Примечание:** метод user() не получает данные пользователя из базы данных. Он создаёт экземпляр UserResource, через который выполняются дальнейшие операции.

## Метод users() 

Предоставляет доступ к ресурсу выборки массива пользователей по установленным фильтрам.

**Сигнатура**

```php
$bts->users() : UsersResource;
```

**Параметры** 

Нет.

**Возвращаемое значение**

``UsersResource`` - объект для выполнения операций над выборкой пользователей.

**Примеры использования**

Получить массив пользователей с истекаемой оплатой до определённой даты:

```php
$users = $bts
    ->users()
    ->expiredBefore(
        date: new DateTimeImmutable("now")
    );
```

Получить массив всех пользователей:

```php
$users = $bts
    ->users()
    ->getAll();
```

## Метод access()

Предоставляет доступ к ресурсу управления записью конкретного доступа к ноде или нодам пользователя.

**Сигнатура**

```php
public function access(
    string $uuid
) : AccessResource;
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``$uuid``|``string``|Открытый уникальный идентификатор записи о доступе|

**Возвращаемое значение**

``AccessResource`` - объект для выполнения операций над конкретной записью о доступе пользователя к ноде или нодам.

**Примеры использования**

Получить информацию о записи доступа:

```php
$access = $bts->
    ->access("f6938796-cf7b-11f1-b89f-38f3ab6d0b2a")
    ->get();
```

Заблокировать запись доступа на уровне базы данных:

```php
$access = $bts
    ->access("f6938796-cf7b-11f1-b89f-38f3ab6d0b2a")
    ->block();
```

## Метод accesses()

Предоставляет доступ к ресурсу выборки массива записей доступов конкретного пользователя по установленным фильтрам.

**Сигнатура**

```php
public function accesses(
    int $userId
) : AccessesResource;
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``$userId``|``int``|Уникальный идентификатор пользователя|

**Возвращаемое значение**

``AccessesResource`` - объект работы с массивом выборки записей доступов конкретного пользователя.

**Важно** 

``$userId`` в данном запросе подразумевает значение поля **ID**, а не **user_id** / **email**. Для его получения, заранее рекомендую запросить данные через метод ``user()``.

```php
$userId = $bts
    ->user(123456789, UserType::TELEGRAM)
    ->get()
    ->id;

$accesses = $bts
    ->accesses($userId);
```

**Примеры использования**

Получить список записей доступов в базе данных без фильтра типов:

```php
$list = $bts
    ->accesses(12)
    ->list();
```

Получить список записей доступов в базе данных с фильтром доступов:

```php
$list = $bts
    ->accesses(12)
    ->list("openvpn");
```

## Метод subs()

Предоставляет доступ к ресурсу работы системы подписок для **OpenVPN** / **Xray** / **иной системы**.

**Сигнатура**

```php
public function subs() : SubsResource;
```

**Параметры**

Нет.

**Возвращаемое значение**

``SubsResource`` - объект, предназначенный для работы с подписками пользователей на конфигурации доступов к VPN-нодам.

> **Важно:** данный объект представляет собой генератор ссылок на получение конфигурационных данных для VPN-приложений. В народе данная система именуется "Подписка". Яркий пример данной функции - **Xray**, предоставляющий ссылку на получение полной конфигурации доступов к VPN-нодам.

**Примеры использования**

Создание ссылки:

```php
$sub = $bts
    ->subs()
    ->create(
        short_code: "1xe21a",
        server_id: 1,
        access_id: 14
    );
```

Получить данные о сгенерированной ссылке:

```php
$sub = $bts
    ->subs()
    ->get(
        short_code: "1xe21a"
    );
```

## Метод server()

Предоставляет доступ к ресурсу связи с удалённой нодой посредством API.

**Сигнатура**

```php
public function server(
    code: $code
) : ServerResource;
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``$code``|``string``|Кодовый идентификатор сервера|

**Возвращаемое значение**

``ServerResource`` - объект, предназначенный для управления конкретным сервером через API.

**Примеры использования**

Получить информацию о выбранном сервере из базы данных:

```php
$server = $bts
    ->server("test_01")
    ->info();
```

Создать контракт на работу с удалённым сервером через API:

```php
$server = $bts
    ->server("test_01")
    ->contract();
```

## Метод servers()

Предоставляет доступ к управлению данными о серверах в локальной базе данных.

**Важно**

В отличии от метода ``server()``, через данный метод **нельзя** создать контракт на удалённое управление сервером.

**Сигнатура**

```php
public function servers() : ServersResource;
```

**Параметры**

Нет.

**Возвращаемое значение**

``ServersResource`` - объект, предназначенный для управление записями о серверах в локальной базе данных.

**Примеры использования**

Получить полный список серверов:

```php
$servers = $bts
    ->servers()
    ->getAll();
```

Получить список серверов, подходящих по фильтрам:

```php
$servers = $bts
    ->servers()
    ->filterBy([
        "name" => "Netherlands",
        "api_endpoint" => "/api"
    ]);
```

## Метод transaction()

Предоставляет доступ к транзакции об оплате доступа к VPN-нодам.

**Сигнатура**

```php
public function transaction() : TransactionResource;
```

**Параметры**

Нет.

**Возвращаемое значение**

``TransactionResource`` - объект, предоставляющий доступ к управлению транзакцией об оплате доступов пользователем.

**Примеры использования**

Получить данные о транзакции:

```php
$transaction = $bts
    ->transaction()
    ->get(123456789);
```

Подтвердить успешную оплату пользователем доступа (завершить транзакцию):

```php
$transaction = $bts
    ->transaction()
    ->success(123456789);
```
