# SecretCipher

Класс, предназначенный для шифрования и дешифрования конфиденциальных данных, включая токены и ключи авторизации, используемые при взаимодействии с удалёнными VPN-нодами через API.

Алгоритм шифрования: ``aes-256-gcm``. В качестве ключа используется значения константы окружения ``BTS_ENCRYPT_KEY``. 

Класс является статическим: его отдельное создание __не предусмотрено__.

## Метод encrypt()

Возвращает зашифрованный переданный ключ.

**Пример использования**

```php
return SecretCipher::encrypt(
    plaintext: "iqiwoiuOIUOIUweqIuejKJ12311",
    key: Env::getString("BTS_ENCRYPT_KEY")
);
```

**Параметры**

|Параметр|Описание|
|:--|:--|
|``plaintext``|Шифруемые данные|
|``key``|Ключ для шифрования данных|

**Возвращаемое значение**

``string`` - зашифрованное значение.

## Метод decrypt()

Дешифрует переданные данные.

**Пример использования**

```php
return SecretCipher::decrypt(
    ecrypted: "bK6z2QJIUEczDs+d65KJyDIOvJfD7P5qMpPMED00w92kWIDpMLR+9GP5yesSajHxtkD2roNiTQ==",
    key: Env::getString("BTS_ECNRYPT_KEY")
);
```

**Параметры**

|Параметр|Описание|
|:--|:--|
|``encrypted``|Зашифрованные данные|
|``key``|Ключ для дешифрования данных|

**Возвращаемое значение**

``string`` - строковое значение.

## Метод generateKey()

Генерирует секрет, предназначенный для шифрования ключей.

**Пример использования**

```php
return generateKey();
```

**Параметры**

Нет.

**Возвращаемое значение**

``string`` - строковое значение.
