# TransactionResource

Ресурс управления информацией о созданных транзакциях оплаты подписки на доступы к VPN-нодам.

## Инициализация

**Через фасад**

```php
$bts = new BotToServer(...);
$transaction = $bts->transaction();
```

**Напрямую**

```php
$transaction = new TransactionResource(
    dbConnector: $database
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``dbConnector``|``IDBConnector``|Класс-адаптер, предназначенный для работы с базой данных. **Необходим при создании ресурса напрямую.**|

## Метод create()

Создаёт запись о проведении транзакции оплаты.

**Пример использования**

```php
return $transaction->create(
    userId: 12,
    provider: 'YOKASSA',
    amount: "129.00",
    currency: "RUB",
    durationDays: 30
);
```

**Параметры**

|Параметр|Тип|Описание|Обязателен?|По умолчанию|
|:--|:--|:--|:--|:--|
|``userId``|``int``|Уникальный идентификатор ``ID`` пользователя в базе данных|Да|-|
|``provider``|``string``|Идентификатор платёжного провайдера|Да|-|
|``amount``|``string``|Сумма транзакции в виде десятичной строки|Да|-|
|``currency``|``string``|Код валюты платежа|Нет|``RUB``|
|``providerPaymentId``|``string``|Идентификатор платежа во внешней платежной системе|Нет|-|
|``durationDays``|``string``|Продолжительность оплаченного периода в днях|Нет|-|
|``description``|``string``|Описание транзакции|Нет|-|
|``metadata``|``array``|Дополнительные данные транзакции|Нет|-|

**Возвращаемый результат**

Числовой идентификатор ``ID`` новой строки в базе данных.

## Метод get()

Возвращает объект ``Transaction`` с информацией о платежной транзакции.


**Пример использования**

```php
return $transaction->get(
    id: 1
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``id``|``int``|Уникальный идентификатор ``ID`` записи транзакции в базе данных|

**Возвращаемое значение**

Объект ``Transaction`` с информацией о транзакции, если информация найдена; ``null``, если информации не найдено.

## Метод getByProviderPayment()

Возвращает объект ``Transaction`` с информацией о платежной транзакции.

**Пример использования**

```php
return $transaction->getByProviderPayment(
    provider: "YOKASSA",
    provider_payment_id: "pay_8f3a91c7d2e64b0a"
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``provider``|``string``|Идентификатор платёжного провайдера|
|``provider_payment_id``|``string``|Идентификатор платежа во внешней платежной системе|

**Возвращаемое значение**

Объект ``Transaction``, если информация о платежной транзакции была найдена; ``null``, если информация не найдена. 

## Метод getByUserId()

Возвращает массив с информацией о платежных транзакциях определённого пользователя.

**Пример использования**

```php
return $transaction->getByUserId(
    user_id: 12
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``user_id``|``int``|Уникальный идентификатор ``ID`` записи выбранного пользователя|

**Возвращаемое значение**

Массив объектов ``Transaction``, если информация о платежных транзакциях найдена; Пустой массив, если информации нет.

## Метод update()

Обновляет информацию о платежной транзакции.

**Пример использования**

```php
return $transaction->update(
    id: 10,
    provider_payment_id: "pay_8f3a91c7d2e64b0a",
    description: "New test transaction",
    metadata: [
        "created_at" => "2026-10-26T22:10:10"
    ]
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``id``|``int``|Уникальный идентификатор ``ID`` записи выбранной транзакции|
|``provider_payment_id``|``string``|Идентификатор платежа во внешней платежной системе|
|``description``|``string``|Описание транзакции|
|``metadata``|``array``|Дополнительные данные транзакции|

**Возвращаемое значение**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.
