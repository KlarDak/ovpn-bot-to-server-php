# SubsResource

Ресурс управления хранением подписок на доступ VPN-нодам.

> Основная задача данного ресурса: **хранение данных подписки на ноды OpenVPN**. Для VPN-нод других протоколов данный ресурс не подходит.

> Документация ресурса актуальна на версию ``3.0.0``. Со следующей минорной версии возможны частичные или полные изменения в работе ресурса.

## Инициализация

**Через фасад**

```php
$bts = new BotToServer(...);
$subs = $bts->subs();
```

**Напрямую**

```php
$subs = new SubsResource(
    dbConnector: $database
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``dbConnector``|``IDBConnector``|Класс-адаптер, предназначенный для работы с базой данных. **Необходим при создании ресурса напрямую.**|

## Метод create()

Создаёт запись о подписке на доступ к VPN-ноде.

**Пример использования**

```php
return $subs->create(
    short_code: "1xABu7",
    server_id: 1,
    access_id: 12
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``short_code``|``string``|Идентификатор ссылки на подписку.|
|``server_id``|``int``|Уникальный ``ID`` записи сервера в базе данных.|
|``access_id``|``int``|Уникальный ``ID`` записи о доступе к VPN-ноде.|

**Возвращаемый результат**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.

## Метод get()

Возвращает объект записи на подписку доступа к VPN-ноде.

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``short_code``|``string``|Идентификатор ссылки на подписку.|

**Возвращаемый результат**

Объект ``Subs``, если результат найден; ``null``, если результат не найден.

## Метод update()

Обновляет адрес короткой ссылки со старой на новую.

**Пример использования**

```php
return $subs->update(
    old_short_code: "1xABu7",
    new_short_code: "7aUjXi"
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``old_short_code``|``string``|Старый идентификатор короткой ссылки.|
|``new_short_code``|``string``|Новый идентификатор короткой ссылки.|

**Возвращаемый результат**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.


## Метод setUsed()

Обозначает ссылку на подписку, как использованную.

**Пример использования**

```php
return $subs->setUsed(
    short_code: "7aUjXi"
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``short_code``|``string``|Идентификатор короткой ссылки на подписку|

**Возвращаемый результат**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.

## Метод drop()

Помечает запись о подписке, как удалённую. **Данное действие является необратимым.**

Несмотря на то, что внутренние методы библиотеки более не могут взаимодействовать с записью, **она остаётся в базе данных**.

**Пример использования**

```php
return $subs->drop(
    short_code: "7aUjXi"
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``short_code``|``string``|Идентификатор ссылки на подписку|

**Возвращаемый результат**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.
