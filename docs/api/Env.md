# Env

Статический класс, предназначенный для предоставления доступа к переменным окружения.

Для его работы нужно заранее загрузить окружение. Для этого заполните файл ``.env`` по инструкции и используйте дополнительную библиотеку, например, ``Dotenv``.

**Расположение**

```php
use CNS\BotToServer\Types\Env;
```

## Методы

Все методы используют **одни и те же аргументы**, однако возвращают **разные значение**, в зависимости от предназначения метода.

**Параметры**

|Параметр|Тип|Описание|Обязателен?|
|:--|:--|:--|:--|
|``key``|``string``|Ключ значения окружения|Да|
|``default``|``int``\|``string``\|``float``\|``bool``|Значение по умолчанию _*_|Нет|

_*_ - может отличаться по типу от метода к методу.

## Метод getString()

Возвращает **строкое** значение. В качестве ``default`` принимает ``string``.

**Пример использования**

```php
return Env::getString("BTS_ENCRYPT_KEY");
```

**Возвращаемое значение**

``string`` - если ключ найден в окружении; Значение ``default`` или пустая строка, если ключ не найден.

## Метод getInt()

Возвращает **целое числовое** значение. В качестве ``default`` принимает ``int``.

**Пример использования**

```php
return Env::getInt("DB_PORT");
```

**Возвращаемое значение**

``int`` - если ключ найден в окружении; Значение ``default`` или ``0``, если ключ не найден.

## Метод getFloat()

Возвращает **число с плавающей точкой** значение. В качестве ``default`` принимает ``float``.

**Пример использования**

```php
return Env::getFloat("TEST_KEY");
```

**Возвращаемое значение**

``float`` - если ключ найден в окружении; Значение ``default`` или ``0.0``, если ключ не найден.

## Метод getBool()

Возвращает **булевое** значение. В качестве ``default`` принимает ``bool``.

**Пример использования**

```php
return Env::getBool("BTS_RUN_DB_TESTS");
```

**Возвращаемое значение**

``bool`` - если ключ найден в окружении; Значение ``default`` или ``false``, если ключ не найден.
