# UserResource

Ресурс управления конкретной выбранной записью из базы данных о пользователе.

## Инициализация

**Через фасад**

```php
$bts = new BotToServer(...);
$user = $bts->user(
    identifier: 123456789,
    userType: UserType::TELEGRAM
);
```

**Напрямую**

```php
$user = new UserResource(
    identifier: 123456789,
    userType: UserType::TELEGRAM
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``identifier``|``int`` \| ``string``|Уникальный идентификатор пользователя|
|``userType``|``UserType``|Тип пользователя по идентификатору|
|``dbConnector``|``IDBConnector``|Класс-адаптер, предназначенный для работы с базой данных. **Необходим при создании ресурса напрямую.**|

## Метод exists()

Проверяет, существует ли выбранный пользователь в базе данных.

**Пример использования**

```php
return $user->exists();
```

**Параметры**

Нет.

**Возвращаемое значение**

``true``, если пользователь существует; ``false``, если пользователя не существует.

## Метод get()

Возвращает объект ``User`` из базы данных с информацией о выбранном пользователе.

**Пример использования**

```php
return $user->get();
```

**Параметры**

Нет.

**Возвращаемое значение**

Объект ``User``, если информация о пользователе найдена; ``null``, если информация не найдена.

## Метод create()

Создаёт нового пользователя.

**Пример использования**

```php
return $user->create(
    language: "RU",
    username: "testuser"
);
```

**Параметры**

|Параметр|Тип|Описание|Обязателен?|
|:--|:--|:--|:--|
|``language``|``string``|Язык пользователя|Да|
|``username``|``string``|Имя пользователя|**Нет**|

**Возвращаемые значения**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.

**Исключения**

Метод выбрасывает исключение ``UserAlreadyExistsException``, если пользователь с данными идентификаторами уже существует в базе данных.

## Метод update()

Обновляет информацию о пользователе.

**Пример использования**

```php
return $user->update(
    email: "newtest",
    language: "EN"
);
```

**Параметры**

|Параметр|Тип|Описание|Обязателен?|
|:--|:--|:--|:--|
|``username``|``string``|Имя пользователя|Нет|
|``email``|``string``|Адрес электронной почты пользователя|Нет
|``language``|``string``|Язык пользователя|Нет|

**Возвращаемое значение**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.

**Особенности работы**

Метод принимает 3 аргумента, но **как минимум 1 из них должен быть заполнен**. Если ни один из аргументов не заполнен, метод вернёт ``false``.

## Метод updatePayment()

Обновляет информацию об оплате доступов к VPN-нодам пользователем.

**Пример использования**

```php
return $user->updatePayment(
    paymentDate: new DateTimeImmutable("now"),
    expiryDate: new DateTimeImmutable("+1 month")
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``paymentDate``|``DateTimeImmutable``|Дата проведения оплаты|
|``expiryDate``|``DateTimeImmutable``|Дата истечения срока действия подписки|

**Возвращаемое значение**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.

## Метод block()

Блокирует пользователя.

> Данное действие **не запрещает** создавать новые доступы к VPN-нодам пользователю посредством внутренних методов библиотеки.

**Пример использования**

```php
return $user->block();
```

**Параметры**

Нет.

**Возвращаемое значение**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.

**Пример использования**

**Параметры**

Нет.

**Возвращаемое значение**

## Метод drop()

Помечает запись о пользователе, как удалённую. **Данное действие является необратимым.**

Несмотря на то, что внутренние методы библиотеки более не могут взаимодействовать с записью, **она остаётся в базе данных**.

**Пример использования**

```php
return $user->drop();
```

**Параметры**

Нет.

**Возвращаемое значение**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.
