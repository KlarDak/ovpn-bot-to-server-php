# ServersResource

Ресурс управления настройками серверов, указанными в базе данных. Не предназначен для управления удалёнными серверами.

## Инициализация

**Через фасад**

```php
$bts = new BotToServer(...);
$servers = $bts->servers();
```

**Напрямую**

```php
$servers = new ServersResource(
    dbConnector: $database
);
```

**Параметры**

|Параметр|Тип|Описание|
|``dbConnector``|``IDBConnector``|Класс-адаптер, предназначенный для работы с базой данных. **Необходим при создании ресурса напрямую.**|

## Метод create()

Создаёт запись о доступном сервере в базе данных.

**Пример использования**

```php
return $servers->create(
    code: "test_01",
    name: "test server",
    host: "192.168.1.12",
    port: 4000,
    api_endpoint: "/api",
    encrypt_secret_code: SecretCipher::encrypt(
        "ioj12oi3joi1j2o3ijo12ij3ojijklajwelkja",
        Env::getString("BTS_ENCRYPT_KEY")
    )
    type: "openvpn",
    subs_url: "https://subs.testserver.local"
);
```

**Параметры**

|Параметр|Тип|Описание|Обязателен?|
|:--|:--|:--|:--|
|``code``|``string``|Уникальный идентификационный код сервера|Да|
|``name``|``string``|Имя сервера|Да|
|``host``|``string``|Хост ноды управления сервером|Да|
|``port``|``int``|Порт ноды управления сервером|Да|
|``api_endpoint``|``string``|Эндпоинт ноды управления сервером|Да|
|``encrypt_secret_code``|``string``|Зашифрованный ключ авторизации на ноде управления сервером|Да|
|``type``|``string``|Тип управляемого сервера|Да|
|``subs_url``|``string``|Ссылка на страницу подписки на загрузку конфигураций доступов|**Нет**|

**Возвращаемое значение**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.

## Метод getAll()

Возвращает массив классов ``Server`` всех серверов, доступных в базе данных.

**Пример использования**

```php
return $servers->getAll();
```

**Параметры**

Нет.

**Возвращаемое значение**

Массив объектов ``Server`` со значениями строк серверов.

## Метод filterBy()

Возвращает массив объектов ``Server``, используя _фильтры_ для получения данных о серверах.

**Пример использования**

```php
return $servers->filterBy(
    conditions: [
        "name" => "TEST SERVER",
        "port" => "4000"
    ]
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``conditions``|``array``|Массив фильтров значений|

**Возвращаемый результат**

Массив объектов ``Server`` со значениями строк серверов.

**Особенности работы метода**

Для работы метода нужно заполнить аргумент-массив подходящими значениями. Список значений:

- ``name`` - имя сервера.
- ``host`` - адрес исходной ноды.
- ``port`` - порт исходной ноды.
- ``api_endpoint`` - эндпоинт исходной ноды.
- ``type`` - тип VPN-сервера, обслуживаемого исходной нодой.
- ``status`` - статус управляемой ноды/сервера.

## Метод get()

Возвращает объект ``Server`` со значениями выбранного сервера.

**Пример использования**

```php
return $servers->get(
    code: "test_01"
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``code``|``string``|Уникальный идентификационный код выбранного сервера|

**Возвращаемое значение**

Объект ``Server``, если искомая информация найдена; ``null``, если информация не найдена.

## Метод update()

Обновляет информацию о сервере.

**Пример использования**

```php
return $servers->update(
    code: "test_01",
    host: "https://192.168.1.19",
    port: 4010,
    api_endpoint: "/newapi"
);
```

**Параметры**

|Параметр|Тип|Описание|Обязателен?|
|:--|:--|:--|:--|
|``code``|``string``|Уникальный идентификатор выбранного сервера|**Да**|
|``name``|``string``|Имя сервера|Нет|
|``host``|``string``|Адрес исходной ноды|Нет|
|``port``|``int``|Порт исходной ноды|Нет|
|``api_endpoint``|``string``|Эндпоинт исходной ноды|Нет|
|``encrypt_secret_code``|``string``|Зашифрованный ключ авторизации на ноде управления сервером|Нет|
|``subs_url``|``string``|Ссылка на страницу подписки на загрузку конфигураций доступов|Нет|

**Возвращаемый результат**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.

## Метод updateStatus()

Обновляет статус сервера.

**Пример использования**

```php
return $servers->updateStatus(
    code: "test_01",
    status: ServerStatusType::ACTIVE
)
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``code``|``string``|Уникальный идентификатор выбранного сервера|
|``status``|``ServerStatusType``|Значение статуса сервера, исходя из вариантов enum-типа ``ServerStatusType``|

**Возвращаемое значение**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.

## Метод drop()

Помечает запись о сервере, как удалённую. **Данное действие является необратимым.**

Несмотря на то, что внутренние методы библиотеки более не могут взаимодействовать с записью, **она остаётся в базе данных**.

**Пример использования**

```php
return $servers->drop(
    code: "test_01"
);
```

**Параметры**

Нет.

**Возвращаемое значение**

``true`` — операция выполнена успешно; ``false`` — операция завершилась неуспешно.
