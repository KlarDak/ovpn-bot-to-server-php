# AccessesResource

Ресурс управления массивом выборки записей о доступах к VPN-нодам выбранного пользователя.

## Инициализация

**Через фасад**

```php
$bts = new BotToServer(...);
$accesses = $bts->accesses(
    user_id: $user_id
);
```

**Напрямую**

```php
$accesses = new AccessesResource(
    dbConnector: $database,
    user_id: $user_id
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``user_id``|``int``|Уникальный ``ID`` записи пользователя в базе данных|
|``dbConnector``|``IDBConnector``|Класс-адаптер, предназначенный для работы с базой данных. **Необходим при создании ресурса напрямую.**|

## Метод list()

Возвращает массив выборки записей доступов к VPN-нодам выбранного пользователя, в том числе _с применением фильтрации по типам VPN-ноды_.

**Пример использования без аргумента**

```php
return $accesses->list()
```

**Пример использования с аргументом фильтра**

```php
return $accesses->list(
    vpn_type: "openvpn"
)
```

**Параметры**

|Параметр|Тип|Описание|Обязателен?|
|:--|:--|:--|:--|
|``vpn_type``|``string``|Тип VPN-ноды|**Нет**|

**Возвращаемое значение**

Массив типов ``Access``, если значения найдены. Пустой массив, если значений нет.

## Метод count()

Возвращает числовое значение количества записей доступов к VPN-нодам, в том числе _с применением фильтрации по типам VPN-ноды_.

**Пример использования без аргумента**

```php
return $accesses->count();
```

**Пример использования с аргументом**

```php
return $accesses->count(
    vpn_type: "openvpn"
);
```

**Параметры**

|Параметр|Тип|Описание|Обязателен?|
|:--|:--|:--|:--|
|``vpn_type``|``string``|Тип VPN-ноды|**Нет**|

**Возвращаемое значение**

Числовое значение **больше или равное нулю**.
