# UsersResource

Ресурс управления выборкой пользователей из базы данных.

## Инициализация

**Через фасад**

```php
$bts = new BotToServer(...);
$users = $bts->users();
```

**Напрямую**

```php
$users = new UsersResource(
    dbConnector: $database
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``dbConnector``|``IDBConnector``|Класс-адаптер, предназначенный для работы с базой данных. **Необходим при создании ресурса напрямую.**|

## Метод expiresBetween()

Возвращает массив объектов ``User`` с истекающим сроком действия подписки в выбранный промежуток дат.

**Пример использования**

```php
return $users->expiresBetween(
    start: new DateTimeImmutable("now"),
    end: new DateTimeImmutable("+1 week")
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``start``|``DateTimeImmutable``|Дата начала выборки|
|``end``|``DateTimeImmutable``|Дата конца выборки|

**Возвращаемый результат**

Массив объектов ``User``, если результат найден; Пустой массив, если результат пустой.

## Метод expiredBefore()

Возвращает массив объектов ``User`` с пользователями, чей срок действия подписки истекает до выбранной даты.

**Пример использования**

```php
return $users->expiredBefore(
    date: new DateTimeImmutable("+1 week")
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``date``|``DateTimeImmutable``|Метка даты выборки|

**Возвращаемый результат**

Массив объектов ``User``, если были найдены пользователи, удовлетворяющие фильтрацию; Пустой массив, если пользователей не найдено.

## Метод getAll()

Возвращает полный список пользователей.

**Пример использования**

```php
return $users->getAll();
```

**Параметры**

Нет.

**Возвращаемое значение**

Массив объектов ``User``, если пользователи найдены; Пустой массив, если пользователей не найдено.

## Метод dropped()

Возвращает массив объектов ``User`` с отметкой ``is_dropped = 1`` (или **удалены из любой выборки**).

**Пример использования**

```php
return $users->dropped();
```

**Параметры**

Нет.

**Возвращаемое значение**

Массив объектов ``User``, если существуют удалённые (``= скрытые из выборки``) пользователи; Пустой массив, если результата нет.
