# Список доступных методов библиотеки

В данном разделе представлено описание публичных методов библиотеки BTS (BotToServer), сгруппированных по функциональным категориям.

Для каждого метода указываются его назначение, параметры, возвращаемое значение, возможные исключения и примеры использования.

## Категории методов

- [BotToServer](BotToServer.md) — главный фасад библиотеки.
- [User](UserResource.md) — управление выбранным пользователем.
- [Users](UsersResource.md) — управление выборкой пользователей.
- [Access](AccessResource.md) — управление конкретным VPN-доступом.
- [Accesses](AccessesResource.md) — управление VPN-доступами.
- [Server](ServerResource.md) — управление удалённой VPN-нодой.
- [Servers](ServersResource.md) — управление информацией VPN-нодами в базе данных.
- [Subscriptions](SubsResource.md) — управление подписками.
- [Transactions](TransactionResource.md) — управление платёжными транзакциями

## Вспомогательные классы

Классы, задача которых заключается в упрощении работы с библиотекой BTS.

- [Env](Env.md) — класс для работы с переменными окружения библиотеки.
- [SecretCipher](SecretCipher.md) - класс для шифрования или дешифрования ключей авторизации/секретов удалённых VPN-нод и их последующего хранения в базе данных.
