# Список доступных методов библиотеки

В данном разделе представлено описание публичных методов библиотеки BTS (BotToServer), сгруппированных по функциональным категориям.

Для каждого метода указываются его назначение, параметры, возвращаемое значение, возможные исключения и примеры использования.

## Категории методов

- BotToServer — главный фасад библиотеки.
- Users — управление пользователями.
- Accesses — управление VPN-доступами.
- Servers — управление VPN-серверами.
- Subscriptions — управление подписками.
- Transactions — управление платёжными транзакциями.
- Node Contracts — взаимодействие с VPN-нодами.
