# ServerResource

Ресурс для получения доступа к управлению пользователями, конфигурациями или системой удалённых VPN-нод.

## Инициализация

**Через фасад**

```php
$bts = new BotToServer(...);
$server = $bts->server(
    code: $code
);
```

**Напрямую**

```php
$server = new ServerResource(
    dbConnector: $database,
    httpClient: $httpClient,
    btsConfig: $btsConfig,
    code: $code
);
```

**Параметры**

|Параметр|Тип|Описание|
|:--|:--|:--|
|``code``|``string``|Уникальный кодовый идентификатор сервера|
|``dbConnector``|``IDBConnector``|Класс-адаптер, предназначенный для работы с базой данных. **Необходим при создании ресурса напрямую.**|
|``httpClient``|``HttpClientInterface``|Класс-адаптер, предназначенный для работы с сетью, преимущественно посредством API. **Необходим при создании ресурса напрямую.**|
|``btsConfig``|``BTSConfig``|Класс управления конфигурацией библиотеки. **Необходим при создании ресурса напрямую.**|

## Метод info()

Возвращает информацию о выбранном сервере.

**Пример использования**

```php
return $server->info();
```

**Параметры**

Нет.

**Возвращаемое значение**

Объект ``Server``, если данные найдены; ``null``, если данные не найдены.

## Метод contract()

Создаёт контракт на управление удалённым сервером.

**Пример использования**

```php
return $server->contract()
```

**Параметры**

Нет.

**Возвращаемое значение**

**Класс контракта** указанного сервера, в случае его наличия в базе конфигурации библиотеки; ``NullContract``, если подходящий контракт не был найден.
