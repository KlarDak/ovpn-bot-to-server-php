# Доступные типы

В данном разделе описаны типы данных, предоставляемые библиотекой BTS, включая типы, используемые стандартными реализациями адаптеров.

> Типы, добавляемые контрактами или классами-адаптерами, не описываются в данном файле документации.

## Access

Объект записи о доступе к VPN-ноде.

**Расположение**

```php
use CNS\BotToServer\Types\Access;
```

|Имя поля|Тип|Описание|Примечание|
|:--|:--|:--|:--|
|``id``|``int``|Внутренний числовой идентификатор записи|_Автоинкремент_|
|``user_id``|``int``|Уникальный ``ID`` записи пользователя-владельца, которому предоставлен доступ к VPN-ноде|-|
|``uuid``|``string``|Идентификатор записи о предоставлении доступа к VPN-ноде|-|
|``name``|``string``|Имя записи о предоставленном доступе, созданное пользователем|_По умолчанию:_ _``null``_|
|``type``|``string``|Тип VPN-ноды, к которой предоставляется доступ|
|``server_id``|``int``|Уникальный ``ID`` записи сервера VPN-ноды из базы данных|
|``created_at``|``DateTimeImmutable``|Дата создания записи|_По умолчанию:_ _``CURRENT_TIMESTAMP``_|
|``is_active``|``bool``|Признак активности доступа к VPN-ноде|_По умолчанию:_ _``true``_|
|``disabled_at``|``DateTimeImmutable``|Дата отключения доступа к VPN-ноде|_По умолчанию:_ _``null``_|
|``is_dropped``|``bool``|Идентификатор псевдоудаления записи из базы данных|_По умолчанию:_ _``false``_|

# ServerStatusType

Перечисление допустимых состояний VPN-ноды.

**Расположение**

```php
use CNS\BotToServer\Types\ServerStatusType;
```

|Значение|Строковое представление|Описание|
|:--|:--|:--|
|``ACTIVE``|_active_|Сервер активен и доступен для подключений|
|``DISABLED``|_disabled_|Сервер отключён|
|``MAINTENANCE``|_maintenance_|Сервер находится на техническом обслуживании|
|``DRAINING``|_draining_|Сервер обслуживает только уже созданные подключения|
|``DROPPED``|_dropped_|Сервер помечен, как удалённый из системы|

# Subs

Объект записи о предоставленной подписке на доступ к VPN-ноде.

> На момент версии ``3.0.0`` используется преимущественно для предоставления доступа к VPN-нодам типа ``OpenVPN``.

|Имя поля|Тип|Описание|Примечание|
|:--|:--|:--|:--|
|``id``|``int``|Внутренний числовой идентификатор записи|_Автоинкремент_|
|``short_code``|``string``|Уникальный идентификатор ссылки-подписки на доступ к VPN-ноде|-|
|``server_id``|``int``|Внутренний ``ID`` записи о сервере|-|
|``access_id``|``int``|Внутренний ``ID`` записи о предоставленном доступе к VPN-ноде|-|
|``created_at``|``DateTimeImmutable``|Дата создания записи о подписке|_По умолчанию: ``CURRENT_TIMESTAMP``_|
|``is_used``|``bool``|Признак использования ссылки-подписки на VPN-ноду|_По умолчанию: ``false``_|
|``used_at``|``DateTimeImmutable``|Дата использования ссылки-подписки|_По умолчанию: ``null``_|
|``is_dropped``|``bool``|Идентификатор псевдоудаления записи из базы данных|_По умолчанию: ``false``_|

# Transaction

Объект записи о проведимой или проведённой платежной транзакции.

|Имя поля|Тип|Описание|Примечание|
|:--|:--|:--|:--|
|``ID``|``int``|Внутренний числовой идентификатор записи|_Автоинкремент_|
|``user_id``|``int``|Уникальный ``ID`` записи пользователя-владельца, который проводит транзакцию|-|
|``provider``|``string``|Идентификатор платежного провайдера|-|
|``provider_payment_id``|``string``|Идентификатор платежа, проводимого платежным провайдером|_По умолчанию: ``null``_|
|``amount``|``string``|Сумма транзакции, с двумя цифрами после запятой|-|
|``duration_days``|``int``|Количество дней, оплаченных данным платежом|_По умолчанию: ``null``_|
|``currency``|``string``|Валюта транзакции|-|
|``status``|``string``|Статус выполнения транзакции|-|
|``description``|``string``|Описание транзакции|_По умолчанию: ``null``_|
|``metadata``|``array``|Дополнительные мета-данные транзакции|_По умолчанию: ``null``_|
|``created_at``|``DateTimeImmutable``|Дата создания записи о транзакции|_По умолчанию: ``CURRENT_TIMESTAMP``_|
|``updated_at``|``DateTimeImmutable``|Дата обновления записи о транзакции|_Пол умолчанию: ``null``_|
|``paid_at``|``DateTimeImmutable``|Дата проведения оплаты по транзакции|_По умолчанию: ``null``_|

# TransactionStatusType

Перечисление допустимых статусов транзакции.

**Расположение**

```php
use CNS\BotToServer\Types\TransactionStatusType;
```

|Значение|Строковое представление|Описание|
|:--|:--|:--|
|``PENDING``|_pending_|Транзакция создава и находится в ожидании оплаты|
|``SUCCEEDED``|_succeeded_|Транзакция завершена успешно|
|``FAILED``|_failed_|Транзакция провалилась в процессе выполнения|
|``CANCELED``|_canceled_|Транзакция была отменена|
|``REFUNDED``|_refunded_|Платёж был возвращён|

# User

Объект записи о пользователе.

**Расположение**

```php
use CNS\BotToServer\Types\User;
```

|Имя поля|Тип|Описание|Примечание|
|:--|:--|:--|:--|
|``ID``|``int``|Внутренний числовой идентификатор записи|_Автоинкремент_|

|``username``|``string``|Username пользователя (преимущественно, в Telegram)|_По умолчанию: ``null``_|
|``language``|``string``|Выбранный язык пользователя|-|
|``created_at``|``DateTimeImmutable``|Дата создания записи|_По умолчанию: ``CURRENT_TIMESTAMP``_|
|``last_activity_at``|``DateTimeImmutable``|Дата последней активности пользователя|_По умолчанию: ``null``_|
|``expired_at``|``DateTimeImmutable``|Дата истечения срока действия доступов к VPN-нодам|_По умолчанию: ``null``_|
|``last_payment_at``|``DateTimeImmutable``|Дата последнего платежа|_По умолчанию: ``null``_|
|``is_active``|``bool``|Признак активности аккаунта пользователя|_По умолчанию: ``true``_|
|``disabled_at``|``DateTimeImmutable``|Дата отключения аккаунта|_По умолчанию: ``null``_|
|``is_dropped``|``bool``|Идентификатор псевдоудаления записи из базы данных|_По умолчанию: ``false``_|
