# Langs

Вспомогательный класс для локализации бота на разных языках.

На момент версии ``dev-2.1`` представлена лишь в **русской** локализации, однако в будущем планируется добавление английского и других языков.

Класс является **статическим**, то есть работает в любой точке библиотеки после инициализации выбора пакета локализации.

## Настройка локализации

```php
use CNS\OvpnBotToServer\Langs\Langs;

// Метод установит русскую локализацию
Langs::setLanguage("RU");
```

Метод ``setLanguage()`` устанавливает пакет локализации. Агрумент ``$lang`` - буквенный индекс пакета - равен названию пакета локализации.

## Иная локация файлов локализации

В случае, если пакета локализации нет в комплекте с директорией, можно изменить директорию с помощью метода ``setMisplacedDir($path)``, где ``$path`` - абсолютная ссылка на новую директорию.

```php
// Пример использования
Langs::setMisplacedDir(__DIR__);
```

## Использование

Для получения слов, используются ключи-локаторы - идентификаторы нужных выражений и/или слов. Список данных идентификаторов перечислен в файле ``__temp.json``, находящимся в директории ``packs/``.

Для получения нужно локализованного выражения, используйте метод ``getWords()`` с аргументом ``$ident`` - идентификатором нужно выражения.

Метод всегда возвращает ``string``. Если идентификатора не существует, вернёт пустую строку.

```php
// Метод вернёт выражение, зафиксированное за ключом 'welcome'

Langs::getWords("welcome");
```

Метод ``getModifiedWords()`` вернёт выражение, которое имеет маски для динамического изменения.

Получает тот же агрумент, что и предыдущий метод, плюс дополнительный ``$modificated`` - массив типа 'ключ -> значение', который используется для изменения выходного выражения.

**Пример:** представим, что в языковом пакете под идентификатором 'welcome' находится выражение "Привет, :name".

```php
// Вернёт выражение "Привет, :name"
Langs::getWords("welcome");

// Вернёт модифицированное выражение - "Привет, Sam"
Langs::getModifiedWords("welcome", [":name" => "Sam"]);
```

## Создание языковых пакетов

Шаблон языковых пакетов находится в папке ``packs/`` в файле ``__temp.json``. В нём имеются действующие **ключи** и их **описание**.

**Пример:**

```json
{
    "welcome": "Приветственное сообщение",
    "welcome_new_user": "Новый пользователь, сообщение",
}
```

Для создания нового языкового пакета, создайте в той же директории файл с идентификатором и форматом ``.json`` и заполните его по шаблону.
